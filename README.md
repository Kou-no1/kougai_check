# 校外学習 チェックポイント通過管理

[アプリを開く](https://kou-no1.github.io/kougai_check/)

## 先生向け｜今使っている行事を引き継ぐ

1. 校外学習アプリで現在使っている Apps Script プロジェクトを開き、元のコードにある `SPREADSHEET_ID` の値を控えます。
2. 同じプロジェクトのバックエンドを、このリポジトリの [Code.gs](./Code.gs) の内容に置き換えます。先頭の `const SPREADSHEET_ID = '';` の引用符の中に、控えた値を貼り付けて保存します。同じプロジェクトにHTMLファイル `Index` を作り、[index.html](./index.html) の内容を貼り付けて保存します。先生向けの画面同梱版テキストを使う場合は、テキスト全体を `Code.gs` に貼り付けるだけで、このステップは完了です。
3. 右上の「デプロイ」→「デプロイを管理」（デプロイの管理）で、現在使っているウェブアプリを選びます。接続先が複数ある場合は、ウェブアプリのURLが [index.html](./index.html) の `GAS_URL` と一致するものを選びます。
4. 鉛筆アイコンで編集し、「バージョン」で「新バージョン」を選んで「デプロイ」を押します。実行ユーザーとアクセスできるユーザーは、現在の設定を引き継ぎます。
5. ウェブアプリの `/exec` URLを学校のGoogleアカウントで開き、既存の行事コードを入力します。以前の招待URLからも、接続できなければ「Googleでこの行事に参加」を選べます。参加者名を入力し、「チャット」タブと、それまでの班・通過時刻が表示されれば更新完了です。

公開ページが従来版のGASに接続できたときは、従来の画面で通過管理を続けられます。「更新を確認」から同じ行事を開き直せます。[Google公式のデプロイ手順](https://developers.google.com/apps-script/concepts/deployments?hl=ja)

## 現地での使い方

- **班の準備**　「組の数」に3、「各組の班数」に6を入力すると「1組1班」から「3組6班」までの18班を登録できます。行事作成後は「設定」で班名を編集し、「設定を保存」を押します。通過時刻も引き継がれます。
- **通過確認**　「通過記録」のタイルを押して通過を記録します。「一覧」で担当チェックポイントを選ぶと、まだ来ていない班が分かります。
- **連絡**　「チャット」で送った内容は、その行事の参加者全員が読めます。名前と送信日時を添えて最新100件を表示します。参加者名は画面上部から変更できます。
