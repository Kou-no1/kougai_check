# 校外学習 チェックポイント通過管理

[参加ページを開く](https://manabitane.jp/kougai_check/?view=guest)

## 外部の引率者がスマホから参加する

先生から届いた**参加用URL**を開き、**8文字の行事ID → 表示する名前**の順に入力します。行事ID入りのリンクでは、名前の入力から始められます。参加者は行事の通過状況を見て、通過の記録・取消と全体チャットへの投稿ができます。行事の作成、班・地点の設定、通過記録の一括リセットは先生用です。

QRを読むとこのサイト内で名前を入力できます。Googleへのログインは不要です。名前の入力まで進めないときは、行事IDを残したまま「参加する」をもう一度押してください。「参加ページを開き直す」が表示されたら、そこから同じ行事を開けます。QR読み取りアプリの中で止まる場合は「参加URLをコピー」を押し、SafariまたはChromeのアドレス欄に貼り付けて開いてください。

## 先生が初回に行う設定

### 1. 先生用を更新して今の行事を引き継ぐ

校外学習アプリの既存の Apps Script プロジェクトで、`コード.gs` と HTML ファイル `Index` に配布版の2ファイルをそれぞれ貼り付けて保存します。既存の `index.html` も使えます。GitHubからコピーする場合は、現在の `SPREADSHEET_ID` の値を控え、更新後のコードの同じ欄に入れます。行事IDと通過記録はこのスプレッドシートから読み込みます。[Code.gs](./Code.gs) ｜ [index.html](./index.html)

「デプロイ」→「デプロイを管理」で**既存の学校用ウェブアプリ**を選び、鉛筆マーク →「新バージョン」→「デプロイ」で更新します。アクセス範囲は学校用の設定にします。既存の先生用URLを学校アカウントで開きます。

### 2. 外部参加用のURLを発行する

1. 同じプロジェクトで **「デプロイ」→「新しいデプロイ」→ 歯車 →「ウェブアプリ」** を選び、説明に「外部参加用」と入力します。
2. **実行するユーザーは「自分」、アクセスできるユーザーは「全員」** を選びます。「全員」はGoogleにログインしていない人も含む設定（`ANYONE_ANONYMOUS`）です。「Google アカウントを持つ全員」ではログインが必要です。
3. 「デプロイ」を押し、表示された **外部参加用のウェブアプリURL**（末尾が `/exec`）をコピーします。このURLは公開ページに設定するデータの接続先です。参加者には、設定済みの参加ページのURLと行事IDを渡します。
4. スマホのプライベートブラウズ／シークレットタブで配布するURLを開き、学校のGoogleアカウントにログインせずに既存IDで参加できることを確認します。

**印刷済みのQRを続けて使う場合**　QRが `https://manabitane.jp/kougai_check/?event=行事ID` を指していれば、そのまま使えます。外部参加用のデプロイURLが変わったときは、公開ページの管理者が [index.html](./index.html) の `<meta name="guest-app-url">` の `content` に、外部公開した `/exec` URLを入れて公開します。公開されたら、印刷済みQRをシークレットタブで開き、同じ行事IDで名前の入力に進めることを確認してください。

匿名の「全員」が選択肢にない場合は、学校のGoogle Workspace管理者に、外部参加用ウェブアプリを匿名公開できるか確認してください。行事IDを知っている人は、その行事の通過記録とチャットを利用できます。[Google公式のアクセス設定](https://developers.google.com/apps-script/manifest/web-app-api-executable?hl=ja) ｜ [デプロイの作成と管理](https://developers.google.com/apps-script/concepts/deployments?hl=ja)

### 3. 招待リンクの共有と、先生の追加（任意）

保存先スプレッドシートのオーナーは、学校アカウントのメールアドレスを確認できれば先生として管理できます。「プロジェクトの設定」→「スクリプト プロパティ」で、必要に応じて次の値を保存します。

| プロパティ | 入れる値 | 用途 |
| --- | --- | --- |
| `GUEST_APP_URL` | 手順2でコピーした外部参加用URL（`/exec` まで） | 先生の画面から、外部参加用のリンクを共有できます。 |
| `TEACHER_EMAILS` | 管理を担当する先生の学校メールアドレス。複数人は半角コンマ区切り | Googleで本人確認できた先生に、行事作成や設定変更を許可します。 |

先生に参加者用画面が表示される場合は、学校用デプロイのURLを、登録した学校アカウントで開いてください。Googleがメールアドレスをアプリに渡さない場合は参加者として扱います。[Google公式のアカウント識別の仕様](https://developers.google.com/apps-script/reference/base/session?hl=ja)

## 現地での使い方

- **班の準備**　「組の数」に3、「各組の班数」に6を入力すると「1組1班」から「3組6班」までの18班を登録できます。行事作成後は「設定」で班名を編集し、「設定を保存」を押します。通過時刻も引き継がれます。
- **通過確認**　「通過記録」のタイルを押して通過を記録します。「一覧」で担当チェックポイントを選ぶと、まだ来ていない班が分かります。
- **連絡**　「チャット」で送った内容は、その行事の参加者全員が読めます。名前と送信日時を添えて最新100件を表示します。参加者名は画面上部から変更できます。
